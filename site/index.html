Intentional UI. Useful UX.

Design constraints, not a promise of perfect taste.

Meaning over decoration

No emoji icons, invented social proof, or automatic glass-and-gradient template. Use coherent SVG icons and real content.

Character over sameness

Choose typography, density, color, and rhythm from the reference or brief. Do not impose one aesthetic on every product.

Behavior beyond screenshots

Check keyboard flow, error states, reflow, long text, and localization. Similar pixels do not prove an accessible interface.

What this is. And isn't.

Does this install a browser or build a site by itself?

No. It installs reusable instructions into a compatible coding agent. Browser/vision tools, model access, and the application's runtime are configured separately. An optional Python helper compares local PNGs.

Is every framework and model tested?

No. CI checks packaging, four agent installation targets, the image helper, and this HTML reference in Chromium. Cross-stack guidance is not a universal runtime guarantee. No controlled model-versus-competitor benchmark has been completed.

Can I reuse any website I find?

Use your own designs, licensed assets, or references you have permission to adapt. Do not bypass access controls, impersonate a service, or copy private content. Public visibility does not grant asset rights.
